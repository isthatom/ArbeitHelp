// About //

For those who actually care

Most interview prep feels like textbooks — slow, generic, and easy to ignore. ArbeitHelp is a focused alternative: pick a role, paste a job description if you have one, and get real, graded practice in minutes.

Built by Omkar (and Claude :P) · open source · no paywall.

// How it works //

01

Pick your role

Choose Software Engineer, Consultant, Data Analyst, UI Designer, and more. Each role has a curated bank plus AI-generated variants.

02

Get graded instantly

AI checks keywords and concepts, gives you a 0–3 score, feedback, and an optional improved answer. Hint-capped at 2/3 if you peek.

03

Keep going

Next question, skip, or end early. See your session recap on the page and all-time trends in Progress.
